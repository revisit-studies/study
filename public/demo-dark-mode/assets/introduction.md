# Dark mode demo

Explore every stimulus and response type in reVISit with a dark study interface:

- Text, numerical, date, and time inputs, including sidebar instructions.
- Single and multiple selection menus, checkboxes, radio buttons, buttons, sliders, Likert scales, and both matrix types.
- All three ranking widgets and a custom React response.
- Markdown, questionnaires, a Vega chart with a reactive response, the drawing library's React component, an image, a video, and local HTML.
- An HTML page that inherits dark mode and the same page with an explicit light-mode override.

Try entering answers, opening menus, selecting options, dragging ranking items, drawing, and playing the video. Answers are optional, so you can skip any example.

Images and video retain their original colors. The drawing canvas also keeps its white paper; the controls around it use the study theme.

The study uses `"colorMode": "dark"` in `uiConfig`.
