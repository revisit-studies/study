# Stroop Test with Factors

This HTML example crosses a five-level `color` factor with a two-level `congruence` factor to generate 10 trials in random order. Each color word appears once with matching ink (`neutral`) and once with a randomly selected different ink color (`incongruent`). The HTML stimulus receives these factor values as parameters and renders the word and ink color.

On every trial, report the **ink color** of the displayed word while ignoring what the word says. Respond with the on-screen buttons or their corresponding number keys.

Try to respond as quickly and accurately as possible.
