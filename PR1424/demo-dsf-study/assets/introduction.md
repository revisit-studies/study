# Data Serialization Format Usability Study

This demo reconstructs the crowd-work study in Section 4 of *Reading Between the Curly Braces: On Textual Data Serialization Format Usability*.

You will complete reading, authoring, and modifying tasks in two data contexts:

- **CONFIG** — a software-package configuration document
- **TABULAR** — a small collection of student records

Each context is expressed in a different textual data serialization format. Use only the editor provided in the study; do not use external tools or AI assistance.

Your responses and time-on-task are recorded for this demo.
